# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Beginners as well as Computer Networks students designing and defending enterprise network architectures.
The owner explicitly needs explanations of what the project does, how to read its
results, and when to use web, CLI, TUI, and API. Show essentials first and explain
technical terms at the point of use; keep advanced details available on demand.
The current owner is building a CIC-307 mini-project; viva presentation is the
working context inferred from idea.md, pending further user preference.

## Product Purpose
Turn presets, custom JSON, or reviewed natural-language input into deterministic
network plans, explained decisions, IOS configurations, and verification results.

## Capabilities and Constraints
Preserve all nine result views, input editing, three presets, packet traces,
failure simulation, security lint, BOM, versions and exports. React and CSS with
no added runtime UI dependencies. Local operation first; deployment follows owner review.
Simulator results must not be presented as real-device certification.

## Brand Commitments
NetArchitect. User requests a presentable and attractive UI; no palette or reference
was supplied. Visual choices are provisional implementation judgment.

## Evidence on Hand
Presets and outputs in backend/presets and exports; real test results and limitations
in docs/project_audit.md. Never invent validation or customer claims.
